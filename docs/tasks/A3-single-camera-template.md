根据用户提供的 VisionMaster 案例，交付一份**可由当前 ComputerVisionFlow 打开**的单相机抓边流程骨架，同时标清可运行子图和未实现的测量步骤，为阶段 B–E 提供共同样例。

# 模板分区

| 区域 | 任务 | 现状建议 |
|---|---|---|
| 01 输入 | 图像输入、模式/运行参数 | 优先使用已有节点 |
| 02 前处理 | 灰度、去噪、边缘提取 | 优先使用已有节点 |
| 03 边缘检测 | 卡尺 ROI、亚像素边缘、直线拟合 | 标记 TODO，除非已有真实实现 |
| 04 几何计算 | 四路边缘交点、点线测量 | 可复用实际兼容的节点 |
| 05 位置校正 | 基准选择、偏差/角度 | TODO |
| 06 结果判定 | OK/NG 与有效性 | TODO |
| 07 输出 | 图像预览、JSON/通信结果 | 可复用已有 Viewer 等节点 |

# Scope

- 生成真实可加载的 `.flow` 案例文件；优先通过当前应用保存产生，不手写臆测格式。
- 利用 A1/A2 功能为流程添加业务名称、Group、Comment。
- 复用已存在的节点建立**经过端口类型校验**的最小可执行链路；例如输入、预处理、线检测与 Viewer，准确链路依赖当前 Node 端口定义。
- 未实现功能用视觉 TODO 标注；若必须创建计算占位节点，需单独先征求授权，不可伪造有效输出。
- 文档注明哪些部分已运行验证、哪些是 UI 骨架。

# Non-goals

- 不为模板重新实现卡尺/标定/PLC/结果逻辑。
- 不假定 Hough_Lines 输出必然与 Line_Intersections 输入匹配，必须查真实端口。
- 不承诺精度、产线联机能力或真正的条件分支执行。
